# 🚗 Radar Eletrônico

Projeto desenvolvido em **Python** para simular o funcionamento básico de um radar eletrônico de trânsito.

O programa recebe a velocidade de um veículo, verifica se o limite da via foi ultrapassado e informa ao usuário a situação correspondente.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos de **Python e lógica de programação**, com o objetivo de praticar estruturas condicionais, entrada de dados e processamento de informações.

A proposta é simular de forma simples uma situação encontrada no dia a dia: verificar a velocidade de um veículo em relação ao limite permitido em uma determinada via.

## ⚙️ Funcionalidades

* Solicitação da velocidade do veículo;
* Verificação do limite de velocidade;
* Identificação de veículos acima do limite permitido;
* Exibição de mensagens de acordo com a situação.

## 🛠️ Tecnologias utilizadas

* **Python 3**
* Entrada e saída de dados pelo terminal
* Estruturas condicionais (`if`, `elif` e `else`)

## ▶️ Como executar

### Pré-requisitos

É necessário ter o **Python 3** instalado no computador.

### Execução

Clone o repositório:

```bash
git clone https://github.com/Soullwoolf/Radar-Eletronico.git
```

Entre na pasta do projeto:

```bash
cd Radar-Eletronico
```

Execute o programa:

```bash
python radar_eletronico.py
```
